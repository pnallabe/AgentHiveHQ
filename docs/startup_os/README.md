This directory contains the complete startup operating system for **AgentHive** — the governance-native credit intelligence platform. Every document was generated from context analysis of the three production codebases in this workspace:

## Core Differentiation

| What we do | Why it matters |
|---|---|
| Alternative-data underwriting for 45M thin-file Americans | +10–22% approval lift without increasing default rates |
| SR 11-7 artifacts auto-generated (MDR, MVR, Model Card) | Reduces MRM documentation from 8 weeks to < 30 minutes |
| OCC/HMDA audit package in a single command | Turns a 6-week exam prep exercise into a 5-minute workflow |
| Continuous fair lending testing (4/5ths rule) | Eliminates ECOA disparate impact risk from first deployment |
| Governance is the architecture, not a feature | Impossible to use decision engine without generating audit evidence |
